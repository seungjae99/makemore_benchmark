01 개발 배경 및 문제 정의
학습 동기

Andrej Karpathy의 makemore 강의는 바이그램 언어 모델을 두 가지 방식—카운트 기반과 신경망—으로 구현하는 과정을 다룬다. 강의에서는 두 접근법의 수식적 동치성을 설명하지만, 실제 구현에서 속도와 정확도가 어떻게 갈리는지는 직접 측정하지 않는다.

이론적으로 두 모델은 같은 확률 분포를 근사하지만, 추론 경로가 다르다. 카운트 기반은 행렬 조회 한 번이고, 신경망은 one-hot 인코딩 → 행렬곱 → exp → 정규화의 연산 사슬을 거친다. 이 구조 차이가 실제 측정값에 어떻게 반영되는지 정량화하는 것이 이 프로젝트의 목적이다.

문제: 바이그램 수준에서 신경망 모델이 카운트 기반 대비 속도와 정확도 양쪽에서 실제로 어느 정도 차이를 보이는가? torch.no_grad()가 추론 속도에 미치는 영향은 유의미한가?
실험 설계 원칙
1
동일 데이터: 두 모델이 완전히 같은 train/test split을 사용한다. 고정 시드(42)로 재현 가능성을 보장한다.
2
두 축 측정: 정확도는 test NLL loss, 속도는 1,000회 샘플링의 평균 ms/sample로 분리 측정한다.
3
신경망 3가지 조건: with_grad / no_grad / detached W를 구분하여 autograd 오버헤드를 정밀하게 분리한다.
4
모듈 분리: count_bigram.py와 neural_bigram.py는 독립 모듈로 유지하고, benchmark.py가 오케스트레이션만 담당한다.

어휘 크기는 26개 소문자 + 구분자 '.' = 27. 두 모델 모두 27×27 행렬을 핵심 파라미터로 사용한다.

03 핵심 구현 상세
Count-based Model

27×27 빈도 행렬 N을 구축한 뒤, Laplace smoothing(+1)을 적용하고 행 단위로 정규화하여 확률 분포 행렬 P를 생성한다.

def build_count_model(words):
    N = torch.zeros((27, 27), dtype=torch.int32)
    # 빈도 행렬 구축
    for w in words:
        chs = ['.'] + list(w) + ['.']
        for ch1, ch2 in zip(chs, chs[1:]):
            N[stoi[ch1], stoi[ch2]] += 1
    # Laplace smoothing + 정규화
    P = (N + 1).float()
    P /= P.sum(1, keepdim=True)
    return P, stoi, itos

샘플링은 P[ix] 행 조회 후 torch.multinomial 한 번으로 완결된다. 연산 복잡도는 O(1)이다.

Neural Model

27×27 가중치 행렬 W를 경사하강법으로 학습한다. 100 epoch, lr=50, L2 정규화(λ=0.01). 손실 함수는 NLL.

for _ in range(100):
    logits = xenc @ W
    counts = logits.exp()
    probs = counts / counts.sum(1, keepdim=True)
    loss = -probs[arange(num), ys].log().mean() \
           + 0.01*(W**2).mean()
    W.grad = None
    loss.backward()
    W.data += -50 * W.grad

추론 시 샘플링마다 전체 forward pass(one-hot → matmul → exp → normalize)를 반복한다.

속도 측정 방법론
1
반복 횟수: 모델별 1,000회 샘플링. 평균 ms/sample 산출로 이상치 영향을 최소화한다.
2
타이머: time.perf_counter() — OS가 제공하는 고해상도 단조 시계. 시스템 시간 변경에 무관하다.
3
세 가지 신경망 조건: (a) W에 requires_grad=True인 채로 샘플링, (b) torch.no_grad() 컨텍스트, (c) W.detach()를 사용하는 기본 경우를 분리 측정하여 autograd 오버헤드를 정밀 분리한다.
4
시드 고정: 각 측정 루프 직전에 torch.Generator().manual_seed(42)를 리셋하여 샘플 수 편차를 제거한다.
설계 결정 — build_neural_model 반환값
참고: build_neural_model은 W.detach()를 반환한다. 추론에서 그래디언트가 불필요하며, 호출자가 실수로 역전파를 실행하는 상황을 원천 차단한다.

with_grad 측정은 W_grad = W.clone().requires_grad_(True)로 별도 복사본을 만들어 수행한다. 이렇게 하면 기본 경로(detached W)와 with_grad 경로를 독립적으로 측정할 수 있다.

핵심 고찰
고찰 1 — 카운트 기반이 양쪽 모두 우세: 바이그램 스케일에서는 확률 테이블 조회가 forward pass보다 빠르고 정확하다. 연산 경로가 단순할수록 추론 오버헤드가 없고, Laplace smoothing이 이산 분포에 잘 맞는 사전확률이기 때문이다.
고찰 2 — no_grad의 효과는 19%에 불과: torch.no_grad()를 적용해도 속도가 2.38× → 2.00× 수준으로만 개선된다. 추론 병목은 autograd 북키핑이 아닌 순전파 연산(matmul + exp + normalize) 자체에 있음을 시사한다.
고찰 3 — 아키텍처가 확장될수록 역전: 컨텍스트 창이 1을 넘어 MLP나 Transformer 구조로 확장되면 조회 테이블은 지수적으로 커져 비실용적이 된다. 신경망의 추론 오버헤드는 그 시점부터 정당화된다.
